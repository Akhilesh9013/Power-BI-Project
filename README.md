# 👨‍💼 HR Analytics Dashboard (Power BI)

## 📌 Project Overview

This project analyzes HR employee data using Power BI to understand employee attrition, job satisfaction, workforce distribution, and overall organizational trends. An interactive dashboard was created to visualize key HR metrics and support better workforce decision-making.

## 🎯 Objectives

- Analyze employee attrition and retention trends  
- Understand workforce distribution across departments and job roles  
- Identify factors affecting employee satisfaction and attrition  
- Track employee demographics and performance insights  
- Build an interactive HR analytics dashboard  

## 🛠 Tools & Technologies

- Power BI  
- Data Cleaning & Transformation  
- Data Modeling  
- DAX Measures  
- Data Visualization  
- HR Analytics  

## 📈 Key Insights

- Identified departments with higher attrition rates  
- Certain age groups and job roles showed higher employee turnover  
- Job satisfaction and work-life balance influenced retention trends  
- Workforce distribution analysis improved HR understanding  

## 🔧 Features

- Interactive HR Dashboard  
- Attrition Analysis  
- Employee Demographics Visualization  
- Department & Job Role Analysis  
- Dynamic Filters and Slicers  
- KPI Cards for HR Metrics  


## 🚀 Impact

Provided valuable insights into employee behavior, attrition patterns, and workforce performance, helping improve HR strategies and employee retention planning.
